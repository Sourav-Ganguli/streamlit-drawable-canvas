# Streamlit - Drawable Canvas Fork

This is a fork of streamlit-drawable-canvas, updated to work with the latest version of Streamlit and to support dependency updates including a migration to Vite

To Install-

pip install git+https://github.com/Sourav-Ganguli/streamlit-drawable-canvas.git
